# Adios Homebrew Tap

Official binary formula for the proprietary [Adios CLI](https://www.adios.dev).
The CLI source remains private; formula releases install checksummed binaries
from [adiosdotdev/cli](https://github.com/adiosdotdev/cli/releases).

## Install

```sh
brew install adiosdotdev/tap/adios
```

## Upgrade

```sh
brew upgrade adiosdotdev/tap/adios
```
